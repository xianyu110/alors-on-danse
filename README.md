## 怎么用

1. 打开 [tryalorsondanse.video](https://tryalorsondanse.video)
2. 上传 Photo 1（键盘手，左）与 Photo 2（舞伴，右）——须为不同的人
3. 选画幅（16:9 贴近横屏翻拍；9:16 适合 Shorts）→ Create
4. Stripe：Single **$8.88** / 3-pack **$16.99** / 10-pack **$39.90**（约 **15 秒**）
